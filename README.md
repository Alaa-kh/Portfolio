# Alaa Khaled Portfolio

Production-ready personal portfolio built with React 19, TypeScript, and Vite.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
npm run typecheck
```

## Structure

- `src/app` — providers, router, config
- `src/features` — home, projects, contact
- `src/shared` — UI, locales, constants, hooks
- `src/assets/projects` — project images (replace SVG covers with real screenshots)

## Editable data

- Projects: `src/shared/constants/projects.ts`
- Skills: `src/shared/constants/skills.ts`
- Services: `src/shared/constants/services.ts`
- Experience placeholders: `src/shared/constants/experience.ts`
- About stats: `src/shared/constants/about.ts`
- Social links: `src/shared/constants/social.ts`
- Copy EN/AR: `src/shared/locales/en.ts`, `src/shared/locales/ar.ts`
